# Agent Runbook

Persistent startup operations for agents working in this repository. Read after
`.AGENT/agent.md`.

## Recurring startup operations

1. Refresh context: read `.AGENT/agent.md` + recent `.AGENT/agent-action-log.md`.
2. Check branch + working tree before editing; preserve existing work.
3. Persist any new standing instruction into the right `.AGENT/` file (not just chat).
4. Use feature branches; keep shared `.AGENT/` state consistent.
